# Invoice Management App

A simple web application to manage invoices, built with HTML, CSS, and JavaScript. It allows users to add, edit, delete, and view invoices with data stored in localStorage.

## Features
- Add and update invoices.
- Delete individual or all invoices with confirmation.
- Display total sales and responsive table.
- Search functionality.

## Setup
1. Clone the repository.
2. Open `index.html` in a browser or use a local server (e.g., `live-server`).
3. Ensure Font Awesome is included via CDN.

## Technologies
- HTML5
- CSS3
- JavaScript
- localStorage
- Font Awesome (for icons)
